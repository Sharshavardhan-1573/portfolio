About

The short version, on record.

HS

I'm Harshavardhan S, a developer who likes taking a project from a blank file to something you can actually click through — usually starting with a real-world problem (like running a hotel front desk) and turning it into working code.

My recent work spans two ends of the stack: responsive, animated front-ends built with HTML, CSS and JavaScript, and lower-level C programs that handle their own file storage, records and logic without a database in sight. Both come from the same instinct — understand exactly how a system works before dressing it up.

I'm currently sharpening those skills at the MANTRA 2026 Summer School, and building this portfolio is itself part of that coursework.
